Known issues

NVIDIA
  • Not tested on NVIDIA cards. GTX 6xx / 7xx and older run on nouveau.
  • Black screen after boot: remove kms from HOOKS in /etc/mkinitcpio.conf, then: 
    sudo mkinitcpio -P

Void Linux
  • No NVIDIA driver on musl: NVIDIA cards run on nouveau only.
  • wpa_supplicant fights iwd over wifi. Turn it off: 
    sudo rm /var/service/wpa_supplicant
