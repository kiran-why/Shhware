Components

The parts of the system you choose in shh config, in three tabs: settings, features, misc. The lists: components/artix_components.txt and components/void_components.txt. Everything else is always installed.

Files below: path in the repo → where the install puts it.

Turned a part off? The next shh update removes its files (except the ones you changed), stops its service and asks whether to remove its packages.

Settings

Install options.

  • mode: copy (default) or link.
    copy: the configs are copies, the repo can be deleted.
    link: the configs are links to the repo, your edits go into it.
  • layouts: keyboard layouts, the first one is the main one. Default: us,ru.
  • switch layout: the keys that switch the layout: Alt+Shift (default), Ctrl+Shift, Super+Space, Caps Lock, Left Alt+Left Shift.
  • dns: DHCP (default), Cloudflare, Quad9, Google.
    Any other: by hand in ~/.config/shh/config.
  • graphics: auto (default) or by hand: AMD, Intel, NVIDIA, Nouveau.
    auto: the drivers for the cards scripts/hardware finds.
    NVIDIA and Nouveau can't be picked together.
  • editor: Vim (default) or Neovim.
    Files:
    config/vim → ~/.config/vim
    config/nvim → ~/.config/nvim
  • file manager: Broot (default) or Yazi, opens on Super+F.
    Files:
    config/broot → ~/.config/broot
    config/sway/features/broot → ~/.config/sway/features/broot
    config/yazi → ~/.config/yazi
    config/sway/features/yazi → ~/.config/sway/features/yazi
  • aur helper, Artix only: yay (default) or paru.
  • pacman, Artix only: colors, parallel downloads, AUR builds on all CPU cores. On by default.
  • nobeep: mutes the motherboard beeper. On by default.
  • maxhz: every screen at its highest refresh rate, also one plugged in later. On by default.
    Files:
    scripts/maxhz → ~/.local/bin/maxhz
    config/sway/features/maxhz → ~/.config/sway/features/maxhz
  • xwayland: X11 programs, after a relogin. Off by default.
    Off: config/sway/features/noxwayland → ~/.config/sway/features/noxwayland
    On: Artix installs xorg-xwayland; on Void it is always installed, sway needs it.

Features

Scripts and sway settings that make the system easier to use. All on by default. Each one keeps its sway lines in its own file in config/sway/features/.

fastfetch

System info in every new foot window: our logo on the left, a box with OS, kernel, CPU, GPU, RAM, disk and more on the right.

To change the logo: put your file in ~/.config/fastfetch/logos/ and write its path in "source" in ~/.config/fastfetch/config.jsonc. No $ in the logo: fastfetch reads $1…$9 as colors. In copy mode the next shh update puts the original config.jsonc back, yours stays next to it as config.jsonc.bak-DATE.

  • Files: config/fastfetch → ~/.config/fastfetch
  • Started by: home/.zshrc → ~/.zshrc
  • Package: fastfetch

autotile

Tiling like Hyprland's dwindle: a new window splits the focused one in half along its longer side. Floating, fullscreen, stacked and tabbed windows are left alone.

  • Files:
    scripts/autotile → ~/.local/bin/autotile
    config/sway/features/autotile → ~/.config/sway/features/autotile
  • Package: none of its own

clipboard

Clipboard history: the last 100 copies, any of them can be copied again. The first line of the history clears it.

  • Keys:
    Super+C: open / close the history
    Enter: copy
    Ctrl+D: delete one
  • Files:
    scripts/clipboard → ~/.local/bin/clipboard
    config/cliphist → ~/.config/cliphist (history size)
    config/sway/features/clipboard → ~/.config/sway/features/clipboard
  • Package: cliphist

record

Screen recording. Drag for a region, click a screen for all of it, Esc cancels. While it records, the bar shows ● rec. Press any of the keys again to stop.

  • Keys:
    Ctrl+Print: no sound
    Ctrl+Alt+Print: with the system sound
    Alt+Print: with the microphone
  • Saved to: ~/media/recordings/
  • Files:
    scripts/record → ~/.local/bin/record
    config/sway/features/record → ~/.config/sway/features/record
  • Package: wf-recorder

screenshot

Screenshots, also copied to the clipboard. Esc cancels.

  • Keys:
    Print: a region
    Shift+Print: all screens
  • Saved to: ~/media/screenshots/
  • Files:
    scripts/screenshot → ~/.local/bin/screenshot
    config/sway/features/screenshot → ~/.config/sway/features/screenshot
  • Package: grim

bluetooth

Bluetooth and its menu: Bluez in the bar menu (Environment). Turn it on / off, pair, connect, disconnect, forget a device. No PIN prompt: pair a keyboard that asks for a PIN in bluetoothctl. No adapter: the menu says so.

  • Files:
    scripts/bluetooth → ~/.local/bin/bluetooth
    config/sway/features/bluetooth → ~/.config/sway/features/bluetooth
  • Packages:
    Artix: bluez, bluez-utils, bluez-s6
    Void: bluez, libspa-bluetooth
  • Service: bluetoothd

scratchpad

Hidden windows: hide a window and bring it back on any workspace.

  • Keys:
    Super+Shift+S: hide the window
    Super+S: show / hide it
  • Files: config/sway/features/scratchpad → ~/.config/sway/features/scratchpad
  • Package: none of its own

screenshare

Screen sharing in the browser.

  • Files: config/sway/features/screenshare → ~/.config/sway/features/screenshare
  • Package: xdg-desktop-portal-wlr
