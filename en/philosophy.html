Shhware Philosophy

Nov 1, 2026 · @kiranchick

What Shhware is

Shhware is software that stays quiet: it starts fast, uses little memory and CPU, and works through the terminal. Many projects today ship heavy, decorated GUIs; Shhware goes the other way.

Every Shhware project follows the rules below.

Core principles

  1. No useless GUI. Terminal first. A GUI is allowed only where there is no way around it: web pages, video, images.
  2. Free software. Anyone can use, study, share and modify it.
  3. Fast and optimized. It starts and responds without delay. It uses as little memory, CPU and disk as the job allows and does no wasted work. It runs well on old and weak hardware too.
  4. Quiet. No needless output, popups, animations or noise.
  5. Minimal. Only what the job needs: no extra features, background processes or decoration.
  6. Few dependencies. Every dependency is something more to install, update and break. Use as few as possible, prefer what the system already has, and add a new one only when the job cannot be done without it.
  7. Does its job. A Shhware program exists to do its job well. Everything else comes second.
