Компоненты

Части системы, которые вы выбираете в shh config, на трёх вкладках: settings, features, misc. Списки: components/artix_components.txt и components/void_components.txt. Всё остальное ставится всегда.

Файлы ниже: путь в репозитории → куда его кладёт установка.

Выключили часть? Следующий shh update удалит её файлы (кроме тех, что вы меняли), остановит её сервис и спросит, удалить ли её пакеты.

Settings

Параметры установки.

  • mode: copy (по умолчанию) или link.
    copy: конфиги скопированы, репозиторий можно удалить.
    link: конфиги — ссылки на репозиторий, ваши правки попадают в него.
  • layouts: раскладки клавиатуры, первая — основная. По умолчанию: us,ru.
  • switch layout: клавиши переключения раскладки: Alt+Shift (по умолчанию), Ctrl+Shift, Super+Space, Caps Lock, левый Alt+левый Shift.
  • dns: DHCP (по умолчанию), Cloudflare, Quad9, Google.
    Любой другой: вручную в ~/.config/shh/config.
  • graphics: auto (по умолчанию) или вручную: AMD, Intel, NVIDIA, Nouveau.
    auto: драйверы для видеокарт, которые находит scripts/hardware.
    NVIDIA и Nouveau вместе выбрать нельзя.
  • editor: Vim (по умолчанию) или Neovim.
    Файлы:
    config/vim → ~/.config/vim
    config/nvim → ~/.config/nvim
  • file manager: Broot (по умолчанию) или Yazi, открывается на Super+F.
    Файлы:
    config/broot → ~/.config/broot
    config/sway/features/broot → ~/.config/sway/features/broot
    config/yazi → ~/.config/yazi
    config/sway/features/yazi → ~/.config/sway/features/yazi
  • aur helper, только Artix: yay (по умолчанию) или paru.
  • pacman, только Artix: цвета, параллельные загрузки, сборка из AUR на всех ядрах. По умолчанию вкл.
  • nobeep: выключает пищалку материнской платы. По умолчанию вкл.
  • maxhz: каждый экран на максимальной частоте обновления, и экран, подключённый позже. По умолчанию вкл.
    Файлы:
    scripts/maxhz → ~/.local/bin/maxhz
    config/sway/features/maxhz → ~/.config/sway/features/maxhz
  • xwayland: программы для X11, после перезахода. По умолчанию выкл.
    Выкл.: config/sway/features/noxwayland → ~/.config/sway/features/noxwayland
    Вкл.: на Artix ставится xorg-xwayland; на Void он стоит всегда, он нужен sway.
  • a11y: скринридеры в программах GTK, после перезахода. По умолчанию выкл.

Features

Скрипты и настройки sway, которые упрощают работу с системой. По умолчанию все включены. Строки sway каждой фичи лежат в её собственном файле в config/sway/features/.

fastfetch

Информация о системе в каждом новом окне foot: слева наше лого, справа рамка с ОС, ядром, CPU, GPU, RAM, диском и другим.

Чтобы поменять лого: положите свой файл в ~/.config/fastfetch/logos/ и впишите путь к нему в "source" в ~/.config/fastfetch/config.jsonc. Без $ в лого: fastfetch читает $1…$9 как цвета. В режиме copy следующий shh update вернёт исходный config.jsonc, ваш останется рядом как config.jsonc.bak-ДАТА.

  • Файлы: config/fastfetch → ~/.config/fastfetch
  • Запускает: home/.zshrc → ~/.zshrc
  • Пакет: fastfetch

autotile

Тайлинг как dwindle в Hyprland: новое окно делит активное пополам по его длинной стороне. Плавающие, полноэкранные, stacked и tabbed окна не трогает.

Перетаскиваемое окно идёт за курсором. Отпустите его над окном в тайлинге, и оно займёт половину, где курсор; над tabbed или stacked окнами оно станет ещё одним из них. Плавающее окно остаётся там, где его отпустили. Esc тоже отпускает окно. Короткое нажатие — просто клик.

  • Клавиши:
    Super+левая кнопка мыши: перетащить окно
  • Файлы:
    scripts/autotile → ~/.local/bin/autotile
    config/sway/features/autotile → ~/.config/sway/features/autotile
  • Пакет: своего нет

clipboard

История буфера обмена: последние 100 копирований, любое можно скопировать снова. Первая строка истории очищает её.

  • Клавиши:
    Super+C: открыть / закрыть историю
    Enter: скопировать
    Ctrl+D: удалить одну запись
  • Файлы:
    scripts/clipboard → ~/.local/bin/clipboard
    config/cliphist → ~/.config/cliphist (размер истории)
    config/sway/features/clipboard → ~/.config/sway/features/clipboard
  • Пакет: cliphist

record

Запись экрана. Выделите область мышью или щёлкните по экрану, чтобы записать его целиком; Esc отменяет. Пока идёт запись, на панели горит ● rec. Чтобы остановить, нажмите любую из клавиш ещё раз.

  • Клавиши:
    Ctrl+Print: без звука
    Ctrl+Alt+Print: со звуком системы
    Alt+Print: с микрофоном
  • Сохраняет в: ~/media/recordings/
  • Файлы:
    scripts/record → ~/.local/bin/record
    config/sway/features/record → ~/.config/sway/features/record
  • Пакет: wf-recorder

screenshot

Скриншоты, заодно копируются в буфер обмена. Esc отменяет.

  • Клавиши:
    Print: область
    Shift+Print: все экраны
  • Сохраняет в: ~/media/screenshots/
  • Файлы:
    scripts/screenshot → ~/.local/bin/screenshot
    config/sway/features/screenshot → ~/.config/sway/features/screenshot
  • Пакет: grim

bluetooth

Bluetooth и его меню: Bluez в меню панели (Окружение). Включить / выключить, подключить новое устройство, подключиться, отключиться, забыть устройство. Запроса PIN нет: клавиатуру, которая просит PIN, подключайте в bluetoothctl. Нет адаптера — меню так и скажет.

  • Файлы:
    scripts/bluetooth → ~/.local/bin/bluetooth
    config/sway/features/bluetooth → ~/.config/sway/features/bluetooth
  • Пакеты:
    Artix: bluez, bluez-utils, bluez-s6
    Void: bluez, libspa-bluetooth
  • Сервис: bluetoothd

scratchpad

Спрятанные окна: спрячьте окно и верните его на любом рабочем пространстве.

  • Клавиши:
    Super+Shift+S: спрятать окно
    Super+S: показать / спрятать его
  • Файлы: config/sway/features/scratchpad → ~/.config/sway/features/scratchpad
  • Пакет: своего нет

screenshare

Показ экрана в браузере.

  • Файлы: config/sway/features/screenshare → ~/.config/sway/features/screenshare
  • Пакет: xdg-desktop-portal-wlr

sing-box

VPN и его меню: VPN в меню панели (Окружение). Работает с подпиской от вашего VPN-провайдера.

  • Меню:
    On/off: включить / выключить
    Locations: выбрать сервер
    Add subscription: вставьте ссылку. Она хранится в /etc/sing-box/subscription, читать её может только root. Потом удалите ссылку из истории буфера (Super+C)
    Update subscription: обновить подписку
    Start at boot: запуск при загрузке, вкл. / выкл.
  • Файлы:
    scripts/vpn → ~/.local/bin/vpn
    config/sway/features/vpn → ~/.config/sway/features/vpn
  • Пакет: sing-box
  • Сервис:
    Artix: sing-box
    Void: shh-vpn
