Структура репозитория

Что где лежит в репозитории и куда это кладёт установка.

install.sh

Настраивает свежую систему: пакеты, драйверы, сервисы, системные файлы, dotfiles. Можно запускать повторно. То, что отличается по дистрибутивам, лежит в system/. Шаги: Установка.

lib/

lib.sh

Общий код install.sh, link.sh и shh: цвета, сообщения, списки, лого. Сам по себе не запускается.

link.sh

Кладёт репозиторий в домашнюю папку, файл за файлом: копиями, а в режиме link — ссылками на репозиторий. Чужой файл переносится в NAME.bak-ДАТА, никогда не удаляется. Что наше — список в ~/.local/state/shh/installed.

РепозиторийКуда ставится
config/~/.config/
home/~/
scripts/~/.local/bin/
wallpapers/~/wallpapers/
lib/*.sh, system/DISTRO/, components/DISTRO_components.txt~/.local/share/shh/

install.sh и shh запускают его сами. Вручную:

  • -n, --dry-run: показать, что будет сделано, ничего не менять;
  • --link: ссылки на репозиторий, ваши правки попадают в него;
  • --copy: копии, репозиторий можно удалить (по умолчанию);
  • -u, --uninstall: удалить наше, вернуть старые файлы (shh uninstall);
  • -h, --help.

scripts/

Меню и инструменты, 22 shell-скрипта, среди них shh. Ставятся в ~/.local/bin/. Что делает каждый: Окружение.

components/

artix_components.txt, void_components.txt: части, которые shh config может выключить, по одной на строку: имя, пакеты, файлы, сервисы, вкладка, значение по умолчанию. Список: Компоненты.

system/

По папке на дистрибутив: artix/, void/. В каждой:

  • distro.sh: то, что делает только этот дистрибутив: пакетный менеджер, сервисы, вход в систему. Функции у всех дистрибутивов одинаковые;
  • services.txt: сервисы, которые запускаются при загрузке;
  • packages/: common.csv — пакеты для всех, и по списку на каждый графический драйвер.
    Artix: amd, intel, nvidia, nvidia-580xx.
    Void: amd, intel.

config/

Ставится в ~/.config/.

ПапкаЧто
sway/sway: клавиши, рабочие пространства, вид, правила окон, программы, которые он запускает; features/ — по файлу на часть
swaybar/панель
swaylock/экран блокировки
foot/терминал и палитра
fzf/вид всех меню
vim/, nvim/редактор
broot/, yazi/файловый менеджер
mako/уведомления
imv/просмотр картинок
fastfetch/информация о системе в терминале
cliphist/размер истории буфера обмена

home/

Ставится в ~/.

  • .zshrc: оболочка;
  • .zprofile: запускает sway на tty1;
  • .local/share/applications/mimeapps.list: какая программа открывает какой тип файлов.

wallpapers/

Ставится в ~/wallpapers/: по картинке на дистрибутив (Artix, Void, Gentoo, CRUX). Найдены в интернете, авторы неизвестны; они не под лицензией MIT репозитория. Подробнее: Окружение: обои.
