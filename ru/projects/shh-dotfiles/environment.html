Окружение

Sway с простой панелью. Меню и инструменты — небольшие shell-скрипты, которые открываются в терминале. Скрипты: scripts/ → ~/.local/bin/. Клавиши: Горячие клавиши.

Сюда же относятся, описаны в Компонентах: autotile, bluetooth, clipboard, maxhz, record, screenshot.

Панель

Вверху. Слева рабочие пространства, по одному ● на каждое. Справа:

  • ● rec: пока идёт запись экрана, клик её останавливает;
  • часы: клик показывает дату, следующий — время;
  • батарея, только на ноутбуках: красная и уведомление при 10% и меньше;
  • лого вашего дистрибутива: клик открывает меню.

Файлы:
config/swaybar/bar → ~/.config/swaybar/bar
config/swaybar/status.sh → ~/.config/swaybar/status.sh

Меню

Super+M или кнопка на панели; то же ещё раз закрывает его. Esc — назад. Bluez и VPN — части, которые можно выключить в shh config (bluetooth, sing-box): после следующего shh update их строка пропадает из меню.

Файл: scripts/menu → ~/.local/bin/menu

Wifi

  • Available networks: подключиться;
  • Known networks: забыть сеть;
  • Check internet: пробует github.com, kernel.org, wikipedia.org;
  • Disconnect: отключиться.

Файл: scripts/wifi → ~/.local/bin/wifi

Volume

  • (+) Volume, (-) Volume: шаг 5%, максимум 100%;
  • Mute/unmute: звук или микрофон;
  • In/out devices: куда идёт звук и откуда берётся.

Файл: scripts/volume → ~/.local/bin/volume, шаг и максимум в начале файла

Bluez

Bluetooth: Компоненты: bluetooth.

VPN

sing-box с подпиской от вашего VPN-провайдера.

  • On/off: включить / выключить;
  • Locations: выбрать сервер;
  • Add subscription: вставьте ссылку. Она хранится в /etc/sing-box/subscription, читать её может только root. Потом удалите ссылку из истории буфера (Super+C);
  • Update subscription: обновить подписку;
  • Start at boot: запуск при загрузке, вкл. / выкл.

Файл: scripts/vpn → ~/.local/bin/vpn

Prefs

  • Svc: включить или выключить сервис прямо сейчас (спросит пароль). После перезагрузки они запускаются так, как сказано в shh config. seatd и dbus помечены: без seatd не работает sway, без dbus — wifi и bluetooth;
  • Light: ярче / темнее, шаг 5%, не ниже 5%: при 0 экран может стать чёрным.

Файлы:
scripts/settings → ~/.local/bin/settings
scripts/brightness → ~/.local/bin/brightness

Power

Exit (выйти из sway), Power off, Reboot, Sleep. Ещё на Super+L. Выбранное выполняется сразу, без «вы уверены?».

Файл: scripts/power → ~/.local/bin/power

Запуск программ

Super+R: все программы из $PATH, с поиском. Терминальные программы открываются в своём окне терминала, остальные — как есть.

Файл: scripts/launcher → ~/.local/bin/launcher

Список клавиш

Super+/: все клавиши sway и что они делают, с поиском. Читает конфиги sway, поэтому новая клавиша появляется сама. Список: Горячие клавиши.

Файл: scripts/keys → ~/.local/bin/keys

Блокировка

Super+Escape: блокирует экран и гасит экраны. Ещё раз Super+Escape — экраны включаются. Пароль можно вводить и при погашенных экранах.

Сам по себе через время экран не блокируется: swayidle нет, на Artix ему нужен elogind.

Файлы:
scripts/lock → ~/.local/bin/lock
config/swaylock/config → ~/.config/swaylock/config

Обои

Самая новая картинка (png, jpg) в ~/wallpapers; если её нет — чёрный фон. Первая установка ставит обои вашего дистрибутива.

Чтобы сменить: положите картинку в ~/wallpapers (или сделайте touch той, что уже там) и нажмите Super+Shift+C.

Файл: scripts/wallpaper → ~/.local/bin/wallpaper

Терминал

foot работает одним сервером, каждый терминал — лёгкое окно footclient. Оболочка — zsh; новое окно показывает fastfetch. Вход на tty1 запускает sway, остальные TTY остаются консолями.

Файлы:
config/foot/foot.ini → ~/.config/foot/foot.ini (там же палитра)
home/.zshrc → ~/.zshrc
home/.zprofile → ~/.zprofile (запускает sway)

В фоне

Скрипты, которые вы сами не запускаете.

sound: запускает PipeWire вместе с sway и останавливает, когда sway закрывается; нет systemd, который делал бы это.
